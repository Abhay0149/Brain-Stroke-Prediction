## 📌 Overview

This project is a **Machine Learning-based Web Application** that predicts the likelihood of a **brain stroke** based on user health data.

💡 The goal is to help in **early detection** and assist in preventive healthcare decisions.

---

## 🚀 Features

✨ User-friendly web interface
📊 Real-time prediction using ML model
🧠 Accurate stroke prediction
⚡ Fast and lightweight Flask app
📱 Responsive design

## ⚙️ How to Run Locally

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Abhay0149/Brain-Stroke-Prediction.git
cd Brain-Stroke-Prediction
```

### 2️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

### 3️⃣ Run the app

```bash
python app.py
```

### 4️⃣ Open in browser

```
http://127.0.0.1:5000/
```

## 📊 Input Features

The model uses:

* Age 👤
* Gender 🚻
* Hypertension 💉
* Heart Disease ❤️
* BMI ⚖️
* Glucose Level 🍬
* Smoking Status 🚬

## 🎯 Output

👉 Predicts whether a person is at **risk of stroke or not**
